   - GET /api/budgets | flip2 budget list - List budgets
   - GET /api/budgets/{id} | flip2 budget get - Get budget details
   - PATCH /api/budgets/{id} | flip2 budget update - Update limit/enable/disable

   - GET /api/budgets/{id}/report | flip2 budget report - Detailed usage report

================================================================================
USAGE EXAMPLES
================================================================================

1. List all budgets:
```bash
./flip2 budget list
```

2. Check Budget Report for an agent:
```bash
./flip2 budget report <budget_id>
```

3. Spawn a Gemini Flash worker with automatic budget:
```bash
./flip2 agent spawn --role gemini-flash-worker --task "Analyze logs"
```
