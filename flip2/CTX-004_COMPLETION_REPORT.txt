PATTERNS DOCUMENTED
================================================================================

PATTERN A: Struct Lifecycle Management
Description: Context stored in struct, canceled in Stop() method
Status: Correct and safe
Used in: queue.go, supervisor.go, workers.go (3 files)
Example:
```go
type Manager struct {
    ctx context.Context
    cancel context.CancelFunc
}

func New() *Manager {
    ctx, cancel := context.WithCancel(context.Background())
    return &Manager{ctx: ctx, cancel: cancel}
}

func (m *Manager) Stop() {
    m.cancel()
}
```

PATTERN B: Function-Level Deferred Cleanup
Description: Context created and immediately deferred in function
Status: Correct and safe
Used in: scheduler.go, httppeer.go (multiple), daemon.go
Example:
```go
func (m *Manager) DoWork(ctx context.Context) error {
    ctx, cancel := context.WithTimeout(ctx, 5*time.Second)
    defer cancel()
    // ... work with context ...
}
```

PATTERN C: Value-Only Contexts
Description: Using WithValue() for adding metadata, no cancellation
Status: Safe by design
Used in: auth/jwt.go, logger/context.go
Example:
```go
ctx := context.WithValue(r.Context(), key, value)
next.ServeHTTP(w, r.WithContext(ctx))
```
