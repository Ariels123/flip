KEY FEATURES
================================================================================

1. Role-Based Hierarchy
   - 3-tier structure: Coordinator → Supervisors → Workers
   - Each role has distinct responsibilities and permissions
   - Clear delegation patterns

2. Permission Model
   - Can spawn agents (role-specific)
   - Can view hierarchy (role-specific)
   - Can assign tasks (role-specific)
   - Can escalate (role-specific)
   - Can aggregate results (role-specific)
   - Can broadcast messages (role-specific)

3. Delegation Budgets
   - Coordinator: Unlimited supervisors
   - Supervisor: Max 5 workers, up to 3 tasks per worker
   - Max 2 concurrent spawns, 10-minute task timeout
   - Prevents resource exhaustion

4. Escalation Control
   - Worker → Supervisor (60s timeout, no approval)
   - Supervisor → Coordinator (300s timeout, no approval)
   - Worker → Coordinator (30s timeout, requires approval)
   - Ensures proper authority flow
