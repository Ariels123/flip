## Recovery Capabilities

The implementation enables crash recovery:

1. **Detection**: `FindRecoverablePipelines()` finds all pipelines in non-terminal states
2. **State Loading**: Full pipeline state, stages, and artifacts can be loaded
3. **Checkpoint Restoration**: Latest checkpoint can be retrieved for resumption
4. **Strategy Determination**: `DetermineRecoveryStrategy()` recommends recovery action
5. **Cascade Cleanup**: `DeletePipeline()` removes all related data safely

## Persistence Guarantees

- **ACID Compliance**: PocketBase/SQLite provides ACID guarantees
- **Atomic Operations**: Individual record saves are atomic
- **Crash Resilient**: All data survives process crashes and power loss
- **Cascading Deletes**: Deleting a pipeline removes all related data automatically
- **Referential Integrity**: Foreign key constraints enforced by database

## Usage Example

```go
// Initialize store with PocketBase app instance
store := NewPipelineStore(pbApp)

// Create and save a pipeline
pipeline := NewPipelineRun("research", input, 2)
if err := store.SavePipeline(pipeline); err != nil {
    log.Fatal(err)
}

// Save stages as they execute
stage := NewStageRun(pipeline.ID, "gather", "gemini", 0)
stage.Status = StageRunning
store.SaveStage(stage)

// Create a checkpoint for recovery
checkpoint := &Checkpoint{
    ID:            generateID(),
    PipelineRunID: pipeline.ID,
    Version:       1,
    PipelineState: serializePipeline(pipeline),
    StageStates:   serializeStages(pipeline.Stages),
    Reason:        CheckpointStageComplete,
}
store.SaveCheckpoint(checkpoint)

// On restart, find and recover pipelines
recoverables, _ := store.FindRecoverablePipelines()
for _, p := range recoverables {
    recovered, _ := store.LoadPipeline(p.ID)
    checkpoint, _ := store.LoadLatestCheckpoint(p.ID)
    // Resume execution...
}
```
